# Deluxe Luxe Restaurant Website

A responsive one-page restaurant website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server for local development.

## Customize
- Edit copy, menu highlights, phone number and map link in `index.html`.
- Replace images in `assets/` while keeping filenames, or update image paths.
- Colors, typography, layout and responsive styles are in `style.css`.
- Scroll reveals, mobile navigation and reading progress bar are in `script.js`.

The website uses the restaurant details supplied in the request. Menu items are presented as highlights; no prices were supplied.
